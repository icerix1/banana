apksig.jar (added in Banana0.50): com.android.apksig classes from Android SDK Build Tools35.0.0 apksigner.jar, converted toDEX by D8 for use on Android. Apache License2.0; see Apache-2.0.txt. Upstream: https://android.googlesource.com/platform/tools/apksig/ . Reproduction helper: tools/signer_dex.py. This is an APK signing/verification tool, not an AI model.

For API23 compatibility only, Java8 utility references are redirected to small original helpers (tools/signcompat-src) by tools/signcompat_patch.py. The APK signing and verification algorithms remain upstream apksig. Utilities include eager streams, basic Base64, Comparator/List helpers and OptionalInt; test-signing/SigningCompatibilityCheck.java compares behavior and signs/verifies a real APK.
